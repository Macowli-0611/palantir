# Premium Frontend Aesthetic Directives

When building or updating user interfaces, adhere to these mandatory visual standards:

1. **No Bland / Default Styling**: Never use generic default buttons, basic bootstrap-style tables, or flat plain white/grey layouts. Always elevate the visual presentation.
2. **Deep Modern Palette**: Use rich dark backgrounds (`#030712`, `#060810`, `#0b0f19`) layered with subtle radial gradients, frosted glass (`backdrop-filter: blur(16px)`), and 1px crisp borders (`rgba(255,255,255,0.08)`).
3. **Typography**: Always import and use modern typography from Google Fonts (e.g. Outfit, Space Grotesk, Syne, JetBrains Mono) with balanced weights, negative letter spacing on titles (`-0.02em`), and legible line heights (`1.6-1.8`).
4. **Micro-Interactions**: Implement hover effects, border spotlights, 3D card tilt where appropriate, and smooth spring transitions (`cubic-bezier(0.16, 1, 0.3, 1)`).
5. **Component Architecture**: Prefer Bento Grid layouts, laser-cut cyber buttons, glowing badges, and telemetry HUD indicators for technical/futuristic products.
