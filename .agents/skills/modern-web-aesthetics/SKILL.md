# Modern Web Aesthetics & UI Architecture

This skill provides the aesthetic foundations of current generation high-end web design (Vercel, Linear, Apple, Aceternity UI, Raycast).

## Visual Directives

1. **No Flat, Lifeless Backgrounds**: Never use pure flat black (`#000000`) or flat grey without ambient depth. Use deep cosmic obsidian (`#030712`, `#08090d`) layered with radial gradient orbs (`radial-gradient(ellipse at 50% 0%, rgba(120, 119, 198, 0.15), transparent 50%)`).
2. **Precision 1px Borders**: Subtle, high-contrast borders with inner highlights (`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.1)`).
3. **Bento Grid Layouts**: Modular asymmetric grid systems where cards vary in column and row span to present hierarchical information dynamically.
4. **Display Typography**: Modern geometric and editorial fonts (e.g. Outfit, Syne, Space Grotesk, Plus Jakarta Sans, Inter Display) paired with crisp monospaced metadata badges.
